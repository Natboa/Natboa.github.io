# Portfolio artwork

Existing approved project artwork, reused from Natboa/Natboa's profile assets and the supplied poster project exports. No synthetic app screens or terrain stages.

- terrain.jpg: JPEG export of the supplied original 03-final-poster.png (1800 x 1200). Contains modified Copernicus Sentinel data 2024; routes from OpenStreetMap contributors under ODbL via Valhalla. Renderer: Shaded Relief Maps / Blender.
- terrain-still.jpg and terrain-process.gif: approved three-stage Lake Titicaca profile showcase. Google Maps screenshot with original attribution, clean satellite export, finished terrain poster. Source manifest: profile-poster-assets/manifest.md and manifest.json.
- phone.webp: approved RadioV2 Android mockup with Android navigation buttons.
- radio.jpg, radio-mobile.jpg: approved RadioV2 two-phone banner and mobile crop.
- radio-desktop.jpg: existing Windows app screenshot.
- video-recorder.jpg: unchanged source artwork from Natboa/browser-video-recorder docs/banner.jpg.
- attend.jpg: existing Attend project illustration.
- social.jpg: resized JPEG export of the original terrain image for link previews.
- manrope.woff2: self-hosted Manrope variable Latin font from Google Fonts, under the included SIL Open Font License.
- favicon.svg: typographic n. mark using native text.
- integrations/: self-hosted service logos for Greg's capability section. Sources and license in integrations/README.md. Previous Greg screenshot assets were removed at the owner's request.

The terrain GIF autoplays and uses native lazy loading. Its picture element selects the still image when reduced motion is requested. All project artwork is visible by default with no expansion clicks.
