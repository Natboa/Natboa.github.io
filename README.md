# Natboa's portfolio

Website source for natboa.dev, published with GitHub Pages from the main branch.

Editorial portfolio for general junior software roles, based on the approved Editorial Studio concept. Plain HTML, CSS and JavaScript; no build step or package install required.

Update the site by editing the HTML, CSS, JavaScript, and assets, then pushing to main. GitHub Pages republishes the site automatically.

Preview locally with `python -m http.server 8767 --bind 127.0.0.1`, then open http://localhost:8767. `index.html` contains content, `styles.css` contains layout and both themes, and `app.js` handles the appearance preference. Greg's section is a concise capability list beside self-hosted integration logos, with no screenshots or extra JavaScript. Logo sources are documented in assets/integrations/README.md.

The system theme is the default; explicit appearance selections persist locally. All project images are visible while scrolling, without expansion controls. The terrain GIF autoplays with no play button; a native picture source selects a still image for reduced-motion preferences. Visuals use native lazy loading and work without JavaScript. Project artwork and attribution are documented in assets/README.md.

Keep CNAME (`natboa.dev`) and .nojekyll when publishing. No contact links or case studies are included, as requested.
