Accessibility

Accessibility features, checks, known limitations, and ways to report a barrier on Natboa's portfolio.

Using this website

This is Natboa's personal software portfolio. Accessibility work on the site is guided by WCAG and Israeli Standard IS 5568. The information below describes the work done and the testing still needed.

Accessibility features

  • Navigate links and controls with Tab and Shift+Tab. A “Skip to content” link moves keyboard focus directly to the main content.
  • Keyboard focus is visible, including on the overlapping project images. Headings and page landmarks describe the structure.
  • Project images have text descriptions. Decorative icons are hidden from screen readers.
  • Use your browser's zoom controls to enlarge the page. The layout adapts to narrow screens.
  • Choose System, Light, or Dark using the Appearance control in the footer. The default follows your device setting.
  • The map preview has a “Stop animation” control. Stopping shows a still image and saves your choice on this device. “Play animation” restarts the sequence.
  • Your device's reduced-motion setting disables the preview animation and interface movement. A still preview is also shown when JavaScript is unavailable.

Checks and known limitations

Last technical check: 6 November 2026.

Checks included automated accessibility scans, keyboard navigation, light and dark themes, and desktop and mobile browser layouts. Automated checks cannot establish full accessibility or legal compliance.

  • A complete manual assessment with NVDA, VoiceOver, and TalkBack has not been performed. This page is not a certified accessibility assessment.
  • Project screenshots contain text within images. Their descriptions explain the image's purpose, rather than transcribing every application screen.
  • Linked project sites, downloads, and GitHub pages are separate services and have not been fully assessed as part of this portfolio check.
  • Accessibility reports currently use GitHub. A GitHub account is required.

Report an accessibility barrier

Contact the site owner, Natboa, by opening an accessibility report on GitHub. You can report in Hebrew or English, describe a barrier, or request an accessible alternative.

Include the affected page, the action you tried, and what prevented you from continuing. Browser and assistive-technology details are helpful if you wish to share them. Reports are public, so please do not include passwords, medical information, or other private details.

מידע והצהרת נגישות

זהו אתר תיק העבודות האישי של Natboa. עבודת הנגישות באתר נעשית בהנחיית WCAG ות״י 5568. המידע בעמוד מתאר את ההתאמות שבוצעו ואת הבדיקות שעדיין נדרשות.

התאמות הנגישות באתר

  • אפשר לעבור בין קישורים ופקדים באמצעות Tab ו־Shift+Tab. הקישור “Skip to content” מעביר את מיקוד המקלדת ישירות לתוכן הראשי.
  • מיקוד המקלדת מסומן באופן ברור, גם בתמונות הפרויקטים החופפות. כותרות ואזורי עמוד סמנטיים מתארים את מבנה האתר.
  • לתמונות הפרויקטים יש תיאור טקסטואלי. סמלים דקורטיביים מוסתרים מקוראי מסך.
  • אפשר להגדיל את העמוד באמצעות בקרת הזום של הדפדפן. הפריסה מותאמת גם למסכים צרים.
  • בקרת Appearance בתחתית העמוד מאפשרת לבחור תצוגה בהירה, כהה או לפי הגדרת המכשיר. ברירת המחדל היא הגדרת המכשיר.
  • לצד תצוגת המפה מופיע כפתור “Stop animation”. העצירה מציגה תמונה קבועה ושומרת את הבחירה במכשיר. הכפתור “Play animation” מפעיל מחדש את הרצף.
  • הגדרת הפחתת תנועה במכשיר מכבה את האנימציה ואת תנועות הממשק. תמונה קבועה מוצגת גם כאשר JavaScript אינו זמין.

בדיקות ומגבלות ידועות

בדיקה טכנית אחרונה: 6 בנובמבר 2026.

נבדקו סריקות נגישות אוטומטיות, ניווט מקלדת, תצוגה בהירה וכהה ופריסות דפדפן במחשב ובגדלים של מסך נייד. בדיקה אוטומטית אינה קובעת נגישות מלאה או עמידה בדרישות הדין.

  • טרם בוצעה בדיקה ידנית מלאה עם NVDA, VoiceOver ו־TalkBack. עמוד זה אינו חוות דעת של מורשה נגישות.
  • צילומי מסך של הפרויקטים כוללים טקסט בתוך תמונות. התיאורים מסבירים את מטרת התמונה ואינם תמלול מלא של כל מסך יישום.
  • אתרי הפרויקטים המקושרים, קובצי ההורדה ועמודי GitHub הם שירותים נפרדים ולא נבדקו במלואם במסגרת בדיקת תיק העבודות.
  • ערוץ הדיווח הנוכחי הוא GitHub, והשימוש בו דורש חשבון GitHub.
